1. Tirez un maximum de ce cours  :  
  Ce cours est destiné aux développeurs web qui ont déjà de bonnes connaissances en HTML,
  CSS et JavaScript, et qui veulent aller plus loin dans le développement front-end 
  avec le framework Angular ( SCSS et TypeScript ) 
   - [Fiche de résumé ](https://course.oc-static.com/7471261/Fiche+re%CC%81sume%CC%81+De%CC%81butez+avec+Angular+2.1.pdf)


2. Découvrez le framework Angular :
   
  Le développement Angular passe par trois langages principaux :
  - le HTML pour structurer.
  - le SCSS pour les styles – le SCSS est une surcouche du CSS qui y apporte des fonctionnalités supplémentaires.
  - le TypeScript pour tout ce qui est dynamique avec un typage strict sur du JavaScript.

3. Installez les dépendances  

- Pour installer le CLI d'Angular, il vous faut une version LTS de Node et npm.
- On installe le CLI avec la commande : 
  > npm i -g @angular/cli
- On peut vérifier la version installée du CLI avec  
  > ng v  


4. Construisez une application Angular avec le CLI
- Une nouvelle application Angular se crée avec  ng new
  >ng new snapface --style=scss --skip-tests=true
- Démarrer le serveur de développement.
  > ng serve
- La balise  <app-root>  correspond à AppComponent.
  > "<app-root>"
